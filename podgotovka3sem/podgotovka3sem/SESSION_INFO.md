## СЛОЖНЫЕ ТЕМЫ - НУЖНА ТРЕНИРОВКА

### std::list - ОЧЕНЬ ТЯЖЕЛО ИДЁТ!!!
Студент путается с итераторами. Ключевые моменты:

1. **У list НЕТ operator[]** - только итераторы!
2. **Цикл по list:**
   ```cpp
   for (auto it = l.begin(); it != l.end(); ++it) {
       *it  // значение
   }
   ```

3. **Удаление из list - ВАЖНО:**
   ```cpp
   for (auto it = l.begin(); it != l.end(); ) {  // БЕЗ ++it здесь!
       if (условие) {
           it = l.erase(it);  // ОБЯЗАТЕЛЬНО присвоить!
       } else {
           ++it;
       }
   }
   ```
   - После erase итератор невалидный
   - erase возвращает итератор на следующий элемент
   - Если не присвоить - undefined behavior

4. **Вставка в list:**
   ```cpp
   l.insert(it, value);  // вставляет ПЕРЕД it
   ```
   - Чтобы вставить ПОСЛЕ текущего - сначала ++it

5. **++it vs it++** - для итераторов лучше ++it (быстрее)

### std::map - были небольшие трудности
- Забывал std:: перед string
- Лишние if при подсчёте (map[key]++ работает само)
- Итерация: `for (auto& pair : myMap)` - pair.first/pair.second

### std::set - освоил нормально
- set хранит только уникальные
- insert() для добавления (не push_back!)
- Можно создать из вектора: `set<int> s(v.begin(), v.end())`

### Типичные ошибки (ЗАПОМНИТЬ!):

| Ошибка | Как было | Как надо |
|--------|----------|----------|
| Присваивание вместо сравнения | `if (x = nullptr)` | `if (x == nullptr)` |
| Не включён последний элемент | `i < 'Z'` | `i <= 'Z'` |
| Два if вместо else if | `if (n>0)... if (m>0)` | `if (n>0)... else if (m>0)` |
| Буква вместо нуля | `i = o` | `i = 0` |
| Забыл точку с запятой | `return 1 + ...` | `return 1 + ...;` |
| Путал имена функций | `aboba(abob->left)` | `abob(aboba->left)` |
| return внутри цикла | `for(...) return f()` | `for(...) f()` |
| Забыл & для адреса | `func(arr[i])` | `func(&arr[i])` |

### Сложные темы (ПОВТОРИТЬ УТРОМ):

**1. Деревья с указателями — ГЛАВНАЯ СЛОЖНОСТЬ**
- `->` для доступа через указатель
- `==` для сравнения с nullptr (НЕ `=`)
- Шаблон: `if (node == nullptr) return 0/базовое_значение;`

**2. Рекурсия**
- База → return (выход)
- else if, не просто if (чтобы не выполнялось оба)
- return в правильном месте (вне вложенных if если нужен всегда)

**3. vector<Node> childs**
- `.size()` для количества
- `&arr[i]` для передачи адреса элемента
