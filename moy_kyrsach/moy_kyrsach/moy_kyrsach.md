	ВВЕДЕНИЕ
Задача коммивояжера (Travelling Salesman Problem, TSP) является одной из классических задач комбинаторной оптимизации и теории графов. Данная задача имеет широкое практическое применение в различных областях: логистике, планировании маршрутов, производстве печатных плат, секвенировании ДНК и многих других.
Суть задачи заключается в следующем: имеется набор городов и известны расстояния между каждой парой городов. Необходимо найти кратчайший маршрут, который начинается в одном из городов, проходит через все остальные города ровно один раз и возвращается в начальный город.
Задача коммивояжера относится к классу NP-полных задач, что означает отсутствие известного алгоритма, решающего её за полиномиальное время для произвольного числа городов. С ростом количества городов n число возможных маршрутов растет факториально: ((n-1)!)/2, что делает переборный подход применимым только для небольших значений n.
Целью данной курсовой работы является разработка программы, реализующей переборный алгоритм решения задачи коммивояжера. Программа должна находить оптимальный маршрут для заданного набора городов и визуализировать.
 
	ПОСТАНОВКА ЗАДАЧИ
Задачей данной курсовой работы является разработка программы, которая решает задачу коммивояжера с использованием переборного алгоритма и выводит результат в формате, совместимом с Graphviz.
Формальная постановка задачи:
Дан полный взвешенный граф G = (V, E), где:
	V={V_0,V_1,…,V_(n-1)} - множество вершин (городов).
	E - множество рёбер, соединяющих все пары вершин.
	w(V_i,V_j) - вес ребра между вершинами vᵢ и vⱼ (расстояние между городами).
Требуется найти гамильтонов цикл минимальной длины, то есть такую перестановку вершин (p_0,p_1,…,p_(n-1)), что сумма: 
L=w(p_0,p_1 )+w(p_1,p_2 )+⋯+w(p_(n-2),p_(n-1) )+w(p_(n-1),p_0)
является минимальной среди всех возможных перестановок.
Найденный маршрут должен удовлетворять следующим свойствам:
	Каждый город посещается ровно один раз.
	Маршрут является замкнутым циклом (возврат в начальный город).
	Общая длина маршрута минимальна.
Пример, демонстрирующий смысл задачи.
Рассмотрим простой граф с четырьмя городами (0, 1, 2, 3). Матрица расстояний между городами представлена в таблице:
	0	1	2	3
0	0	10	15	20
1	10	0	35	25
2	15	35	0	30
3	20	25	30	0
Таблица 1 – Пример матрицы 
Для данного графа существует несколько возможных маршрутов. Рассмотрим два из них:
Маршрут 1: 0 → 1 → 2 → 3 → 0.
Длина: 10 + 35 + 30 + 20 = 95.
Маршрут 2: 0 → 1 → 3 → 2 → 0.
Длина: 10 + 25 + 30 + 15 = 80.
Как видно из примера, разные маршруты имеют различную длину. Оптимальным является маршрут 0 → 1 → 3 → 2 → 0 с длиной 80.
Подробное описание задачи коммивояжера и методов её решения можно найти в классической литературе по теории алгоритмов и комбинаторной оптимизации [1, 2].
 
	АЛГОРИТМ
	 Основные идеи алгоритма
	Переборный алгоритм решения задачи коммивояжера основан на методе полного перебора (brute force). Основная идея заключается в том, чтобы рассмотреть все возможные маршруты обхода графа и выбрать среди них маршрут с минимальной длиной.
	Генерация всех возможных перестановок вершин графа.
	Для каждой перестановки вычисление длины соответствующего маршрута.
	Отслеживание минимальной найденной длины и соответствующего маршрута.
	После рассмотрения всех перестановок возврат оптимального решения.
Для генерации перестановок используется стандартная функция библиотеки STL std::next_permutation, которая позволяет эффективно перебрать все перестановки в лексикографическом порядке.
	 Шаги алгоритма
Алгоритм состоит из следующих шагов:
	Инициализация минимального расстояния значением бесконечности (или максимальным целым числом).
	Создание начальной перестановки вершин (0, 1, 2, ..., n-1).
	Для текущей перестановки:
	Вычислить длину маршрута, проходящего через вершины в заданном порядке.
	Добавить расстояние от последней вершины до первой (замыкание цикла).
	Если длина текущего маршрута меньше минимальной найденной:
	Обновить минимальное расстояние.
	Сохранить текущую перестановку как оптимальный маршрут.
	Перейти к следующей перестановке.
	Если все перестановки рассмотрены, вернуть оптимальный маршрут и его длину. Иначе перейти к шагу 3.

	 Структуры данных
В программе используются следующие структуры данных из библиотеки STL:
	Матрица смежности графа std::vector<std::vector<int>> graph
Двумерный динамический массив (вектор векторов), где graph[i][j] хранит расстояние от вершины i до вершины j. Размер матрицы: n×n, где n — количество вершин.
	Массив вершин (маршрут) std::vector<int> path
Одномерный динамический массив, хранящий последовательность вершин маршрута. Размер: n элементов.
	Структура результата
  struct TSPResult {
      std::vector<int> bestPath;  // Оптимальный маршрут
      int minDistance;            // Минимальная длина
  };
Структура для хранения результата решения задачи, содержащая оптимальный маршрут и его длину.
Строки для имен файлов std::string filename Используются для хранения имен входных и выходных файлов.
	 Анализ сложности
Временная сложность: Переборный алгоритм рассматривает все возможные перестановки n вершин. Количество перестановок равно n!.
Для каждой перестановки вычисляется длина маршрута, что требует O(n) операций (n-1 ребро в пути + 1 ребро для замыкания цикла).
Таким образом, общая временная сложность алгоритма: O(n! ×n)=O(n ×n!).
Для практических целей можно считать сложность O(n!), так как факториальный рост доминирует.
Пространственная сложность:
	Матрица смежности: O(n²).
	Массив текущей перестановки: O(n).
	Хранение лучшего маршрута: O(n).
Общая пространственная сложность: O(n²).
Оценка времени работы:
Для графа из n вершин количество рассматриваемых маршрутов:
	n = 3: 6 маршрутов.
	n = 4: 24 маршрута.
	n = 5: 120 маршрутов.
	n = 10: 3 628 800 маршрутов.
	n = 15: ≈1.3 × 10¹² маршрутов.

Переборный алгоритм применим только для небольших значений n (обычно n ≤12-15), так как факториальный рост делает его непрактичным для больших графов.

	 Запуск программы
	Программа запускается из командной строки с двумя обязательными параметрами:
  Синтаксис:
  ./tsp <входной_файл> <выходной_файл>
  Параметры:
	<входной_файл> — путь к файлу с описанием графа.
	<выходной_файл> — путь к файлу для сохранения результата в формате DOT.

  ./tsp input.txt output.dot.

	 Формат входного файла
Входной файл должен содержать описание графа в виде матрицы смежности.
Структура файла:
	Первая строка: целое число n — количество вершин (городов).
	Следующие n строк: матрица смежности размером n×n, где элемент в позиции (i, j) представляет расстояние от вершины i до вершины j.
Требования:
	Матрица должна быть симметричной (расстояние от i до j равно расстоянию от j до i).
	Диагональные элементы равны 0 (расстояние от вершины до самой себя).
	Все расстояния — неотрицательные целые числа.

	Объявление ориентированного графа digraph TSP.

	Общую длину оптимального маршрута.

	ЗАКЛЮЧЕНИЕ
В ходе выполнения курсовой работы была разработана программа для решения задачи коммивояжера с использованием переборного алгоритма.
Реализованная программа обладает следующими возможностями:
	Загрузка графа из файла в виде матрицы смежности.
	Поиск оптимального маршрута методом полного перебора всех возможных перестановок.
	Вывод результата в формате Graphviz DOT для последующей визуализации.
	Обработка ошибок ввода-вывода и корректная работа с командной строкой.
Программа написана на языке C++ с использованием контейнеров стандартной библиотеки STL, что обеспечивает эффективное управление памятью и удобство работы с данными. Код снабжен комментариями в формате Doxygen, что упрощает его понимание и дальнейшую модификацию.
Проведенное тестирование на трех примерах различной сложности (графы с 3, 4 и 5 вершинами) подтвердило корректность работы алгоритма.
Программа успешно находит оптимальные маршруты и сохраняет результаты в требуемом формате.
Следует отметить, что переборный алгоритм имеет факториальную временную сложность O(n!), что ограничивает его применимость графами малого размера (обычно не более 12-15 вершин). Для решения задачи коммивояжера на больших графах необходимо использовать приближенные или эвристические алгоритмы, такие как метод ветвей и границ, генетические алгоритмы или метод имитации отжига.
Тем не менее, реализованный переборный алгоритм гарантирует нахождение точного оптимального решения и может служить эталоном для проверки корректности других, более эффективных алгоритмов.
